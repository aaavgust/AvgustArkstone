# Changelog

## 1.1.1 — Облако без ключей
- Облако отвечает сразу после включения, без регистрации и ключей: бесплатные Kilo и OVH подключаются сами.
- Список моделей этих провайдеров сверяется с их сайтом при каждом запуске облака — устаревшие модели не мешают ответу.

## 1.1.0 — Облако
- Новый режим **«Облако» (FreeLLMAPI)**: бесплатные облачные модели Google, Groq, OpenRouter, Cerebras, Mistral и других через один локальный маршрутизатор. Выключен по умолчанию — офлайн остаётся основным.
- В выборе модели чата и кода — «Облако · авто / умная / быстрая»: маршрутизатор сам выбирает провайдера и переключается на другой, когда кончается лимит. Под ответом («Для опытных») видно, какая модель ответила.
- «Настройки → Облако»: включение, панель ключей провайдеров (ключи хранятся зашифрованными на диске Arkstone), состояние и остановка.
- Облако запускается с первым вопросом и само останавливается через 15 минут простоя или сразу при выключении интернета.

## 1.0.0 — Avgust Arkstone
- Новое имя: Arkstone теперь называется **Avgust Arkstone**. Данные на диске (папки Arkstone, Projects, Images) остаются на месте.
- Полная переработка: надёжное ядро на Rust с тестами, безопасные файловые операции (удаление — в Корзину), watchdog и отчёты о сбоях, простой без нагрузки.
- Новый дизайн в бренде a_a_avgust, тёмная и светлая темы, русский и английский.
- Режим «Голос»: речь → ответ → озвучка, общая история с чатом.
- Карты в базе знаний, рекомендации моделей под каждый Mac.
- Нехватка памяти: предупреждение до запуска модели и кнопки «Повторить на модели полегче» / «Освободить память и повторить».
- Поиск в интернете показывает только источники по теме вопроса.
- Обновления с GitHub (aaavgust/AvgustArkstone), подписанные ключом автора.
