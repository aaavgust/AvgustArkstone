# Changelog

## 1.0.0 — Avgust Arkstone
- Новое имя: Arkstone теперь называется **Avgust Arkstone**. Данные на диске (папки Arkstone, Projects, Images) остаются на месте.
- Полная переработка: надёжное ядро на Rust с тестами, безопасные файловые операции (удаление — в Корзину), watchdog и отчёты о сбоях, простой без нагрузки.
- Новый дизайн в бренде a_a_avgust, тёмная и светлая темы, русский и английский.
- Режим «Голос»: речь → ответ → озвучка, общая история с чатом.
- Карты в базе знаний, рекомендации моделей под каждый Mac.
- Нехватка памяти: предупреждение до запуска модели и кнопки «Повторить на модели полегче» / «Освободить память и повторить».
- Поиск в интернете показывает только источники по теме вопроса.
- Обновления с GitHub (aaavgust/AvgustArkstone), подписанные ключом автора.
